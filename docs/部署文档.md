# Kubengine 部署文档

## 一、前期准备

### 1.1 上传并解压安装包

将 `kubengine.tar.gz` 上传到目标服务器，并解压缩：

```bash
scp kubengine.tar.gz root@192.168.1.100:/opt/
ssh root@192.168.1.100
cd /opt/
tar -zxf kubengine.tar.gz
```

### 1.2 激活虚拟环境

```bash
cd /opt/kubengine/
source env/bin/activate
```

> **说明**：后续所有 `kubengine` 与 `kubengine-k8s` 命令均需在虚拟环境中执行。

## 二、集群配置

### 2.1 配置集群信息

```bash
kubengine cluster config \
  --hosts 172.31.96.11,172.31.96.10,172.31.96.1,172.31.96.12,172.31.96.14,172.31.96.13 \
  --hostname-map 172.31.96.11:master01,172.31.96.10:master02,172.31.96.1:master03,172.31.96.12:node01,172.31.96.14:node02,172.31.96.13:node03 \
  --username root --password Avic@123
```

### 2.2 查看集群配置

```bash
kubengine cluster show
```

### 2.3 关闭防火墙

```bash
kubengine cluster disable-firewalld
```

## 三、调整部署配置

编辑配置文件：

```bash
vim /opt/kubengine/config/application.yaml
```

#### 单 master 配置示例

```yaml
kubernetes:
  master:
    ip: 按照要求填写        # master 节点 IP
    schedulable: false
  worker:
    ips: [按照要求填写]      # worker 节点 IP 列表
  cidr:
    pod: 10.96.0.0/16
    service: 10.97.0.0/16
  loadbalancer:
    ip-pools:
      - 按照虚拟交换机保留IP地址填写    # 示例: 172.31.57.30-172.31.57.40
```

#### 高可用（多 master）配置示例

```yaml
kubernetes:
  master:
    ip: 172.31.96.11                       # 第一个 master（必须）
    additional_ips:
      - 172.31.96.10                       # 附加 master02
      - 172.31.96.1                        # 附加 master03
    control-plane-endpoint: 172.31.96.100  # VIP（用于 apiserver HA）
    interface: ens31                       # 网卡名（可选，默认自动检测）
    schedulable: false
  worker:
    ips:
      - 172.31.96.12
      - 172.31.96.14
      - 172.31.96.13
  cidr:
    pod: 10.96.0.0/16
    service: 10.97.0.0/16
  loadbalancer:
    ip-pools:
      - 按照虚拟交换机保留IP地址填写    # 示例: 172.31.57.30-172.31.57.40
```

## 五、验证部署配置

```bash
# 显示当前配置
kubengine-k8s config --show
# 验证配置
kubengine-k8s config --validate
```

> **注意**：部署前务必执行 `--validate` 校验，确保配置无误。

## 六、准备数据盘（Longhorn）

在 worker 节点上格式化并挂载数据盘供 Longhorn 使用：

```bash
mkfs.ext4 /dev/vdc
umount /media/lanqing/vdc
mkdir /var/lib/longhorn/
mount /dev/vdc /var/lib/longhorn/
```

#### 批量配置 worker 节点（可选）

通过 `kubengine` 在多个 worker 节点批量执行，实现开机自动挂载：

```bash
# 写入开机挂载并生效
kubengine cluster exec \
  'echo "UUID=$(blkid -s UUID -o value /dev/vdc) /var/lib/longhorn ext4 defaults 0 0" >> /etc/fstab; mount -a' \
  --hosts 172.31.96.12,172.31.96.13,172.31.96.14

# 验证挂载结果
kubengine cluster exec 'lsblk -f | grep longhorn' \
  --hosts 172.31.96.12,172.31.96.13,172.31.96.14
```

## 七、部署应用

```bash
kubengine-k8s deploy
```

> **日志路径**：部署详细过程日志位于 `/opt/kubengine/logs/k8s_cli.log`，可用于排查问题。

## 八、K8s 部署后初始化

等待所有 Pod 状态为 Running 后，依次执行以下初始化操作：

```bash
# 1. 初始化 Harbor 项目
kubengine-k8s init-harbor

# 2. 推送集群节点离线镜像到 Harbor（后续扩容节点可直接拉取）
kubengine-k8s push-images

# 3. 批量推送应用镜像与 Helm Charts 到 Harbor
kubengine-k8s sync-bitnami import-dir /root/offline-deploy/bitnami-bundles/

# 4. 初始化应用配置
kubengine app init-data
```

## 九、配置 API 服务（systemd 托管）

将 `kubengine app run` 配置为 systemd 服务，实现开机自启与自动恢复。

### 9.1 创建 service 文件

```bash
cat > /usr/lib/systemd/system/kubengine-api.service << 'EOF'
[Unit]
Description=KubeEngine API Service
After=network.target

[Service]
Type=simple
User=root
Environment="PATH=/usr/bin:/usr/local/bin"
ExecStart=/opt/kubengine/env/bin/kubengine app run
ExecReload=/bin/kill -HUP $MAINPID
KillMode=process-group
TimeoutStopSec=10
KillSignal=SIGTERM
FinalKillSignal=SIGKILL
Restart=always
RestartSec=10
StandardOutput=journal
StandardError=journal

[Install]
WantedBy=multi-user.target
EOF
```

### 9.2 启动并设置开机自启

```bash
systemctl daemon-reload
systemctl enable --now kubengine-api
```

### 9.3 验证服务状态

```bash
# 查看服务状态
systemctl status kubengine-api

# 查看实时日志
journalctl -u kubengine-api -f
```

服务默认监听 `0.0.0.0:8080`，通过浏览器访问 `http://<服务器IP>:8080` 即可打开管理界面。
