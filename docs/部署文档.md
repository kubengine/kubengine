# Kubengine 部署文档

## 一、前期准备

### 1.1 上传并解压安装包

将 `kubengine.tar.gz` 上传到目标服务器，并解压缩：

```bash
scp kubengine.tar.gz root@192.168.1.100:/opt/
ssh root@192.168.1.100
cd /opt/
tar -zxf kubengine.tar.gz
```

### 1.2 激活虚拟环境

```bash
cd /opt/kubengine/
source env/bin/activate
```

> **说明**：后续所有 `kubengine` 与 `kubengine_k8s` 命令均需在虚拟环境中执行。

## 二、集群配置

### 2.1 配置集群信息

```bash
kubengine cluster configure-cluster \
  --hosts 172.31.96.11,172.31.96.10,172.31.96.1,172.31.96.12,172.31.96.14,172.31.96.13 \
  --hostname-map 172.31.96.11:master01,172.31.96.10:master02,172.31.96.1:master03,172.31.96.12:node01,172.31.96.14:node02,172.31.96.13:node03 \
  --username root --password Avic@123
```

### 2.2 查看集群配置

```bash
kubengine cluster show-cluster-config
```

### 2.3 关闭防火墙

```bash
kubengine cluster disable-firewalld
```

## 三、调整部署配置

编辑配置文件：

```bash
vim /opt/kubengine/config/application.yaml
```

#### 单 master 配置示例

```yaml
kubernetes:
  master:
    ip: 按照要求填写        # master 节点 IP
    schedulable: false
  worker:
    ips: [按照要求填写]      # worker 节点 IP 列表
  cidr:
    pod: 10.96.0.0/16
    service: 10.97.0.0/16
  loadbalancer:
    ip-pools:
      - 按照虚拟交换机保留IP地址填写    # 示例: 172.31.57.30-172.31.57.40
```

#### 高可用（多 master）配置示例

```yaml
kubernetes:
  master:
    ip: 172.31.96.11                       # 第一个 master（必须）
    additional_ips:
      - 172.31.96.10                       # 附加 master02
      - 172.31.96.1                        # 附加 master03
    control-plane-endpoint: 172.31.96.100  # VIP（用于 apiserver HA）
    interface: ens31                       # 网卡名（可选，默认自动检测）
    schedulable: false
  worker:
    ips:
      - 172.31.96.12
      - 172.31.96.14
      - 172.31.96.13
  cidr:
    pod: 10.96.0.0/16
    service: 10.97.0.0/16
  loadbalancer:
    ip-pools:
      - 按照虚拟交换机保留IP地址填写    # 示例: 172.31.57.30-172.31.57.40
```

scp offline-deploy.tgz root@192.168.1.100:/root/

## 五、验证部署配置

```bash
# 显示当前配置
kubengine_k8s config --show
# 验证配置
kubengine_k8s config --validate
```

> **注意**：部署前务必执行 `--validate` 校验，确保配置无误。

## 六、准备数据盘（Longhorn）

在 worker 节点上格式化并挂载数据盘供 Longhorn 使用：

```bash
mkfs.ext4 /dev/vdc
umount /media/lanqing/vdc
mkdir /var/lib/longhorn/
mount /dev/vdc /var/lib/longhorn/
```

#### 批量配置 worker 节点（可选）

通过 `kubengine` 在多个 worker 节点批量执行，实现开机自动挂载：

```bash
# 写入开机挂载并生效
kubengine cluster execute-cmd \
  --hosts 172.31.96.12,172.31.96.13,172.31.96.14 \
  --cmd 'echo "UUID=$(blkid -s UUID -o value /dev/vdc) /var/lib/longhorn ext4 defaults 0 0" >> /etc/fstab; mount -a'

# 验证挂载结果
kubengine cluster execute-cmd \
  --hosts 172.31.96.12,172.31.96.13,172.31.96.14 \
  --cmd 'lsblk -f | grep longhorn'
```

## 七、部署应用

```bash
kubengine_k8s deploy
```

> **日志路径**：部署详细过程日志位于 `/opt/kubengine/logs/k8s_cli.log`，可用于排查问题。
