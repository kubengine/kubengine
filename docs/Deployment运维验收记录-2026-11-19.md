## 浏览器验收

使用 `playwright-cli` 访问仅监听 `127.0.0.1:18086` 的隔离服务。身份、权限、会话、
SQLite、审计、版本和 HTTP 路由使用实际实现，Kubernetes 使用模拟 SDK。测试密码和
账号仅存在于临时数据库；没有访问正式数据库或更改真实 Kubernetes 资源。

- 实际表单登录管理员、命名空间运维和只读用户，检查按钮与进度访问边界。
- 运维缩容到 0 必须勾选停服确认；扩容、刷新恢复、HPA 禁止扩缩容均通过。
- 重启显示更新策略，可键盘取消；模拟 SDK 响应丢失后只有一次模板写入，最终只读核实完成。
- `ProgressDeadlineExceeded` 和 `ImagePullBackOff` 诊断可见，任意敏感上游文本不回显；
  关联事件和 Pod 日志入口正确。
- 弹窗打开后撤销运维写权限，提交返回 403 后入口清除；只读直接写入、跨命名空间查询
  均为 403，保持有效登录；管理员可查看同一资源操作。
- 375 像素页面与确认弹窗、键盘焦点及 Escape、表格内部滚动、轮询暂时故障的内联反馈
  与恢复均检查。诊断、请求编号和 UID 可换行，不撑宽页面。
- 资源删除后的 manifest 404 不阻止授权范围内的操作历史展示；前端等待与刷新不重放写入。双击确认并模拟 HTTP 响应丢失，保留请求标识后刷新恢复，确认只有一次提交和一次模拟 SDK 写入。

验收中修复了移动端弹性子项最小宽度、轮询错误模式导致内联提示被统一助手隐藏、
历史记录按钮名称歧义，以及资源删除时父页面阻挡操作历史的问题。异步提交按目标管理
请求中状态，切换资源后旧响应不会更新其他资源的展示。

## 静态产物与发布边界

最终前端 `dashboard/dist` 已完整同步至 `kubengine/src/web/static`，93 个文件的集合及
SHA-256 一致。没有引入字体、图标或其他外网运行时资源，也没有引入新依赖。审计列表、筛选及详情已补齐“集群已接受 / 未执行或已拒绝 / 写入待核实”的中文结果，避免把写入受理误显示为发布成功。

正式发布时须使用现有安装路径和连接配置，先确认后台无待切换操作，备份并核对数据库、
历史密钥、身份密钥及配置，再更新源码/静态产物、运行幂等建表、重启 `kubengine-api`
和 `kubengine-image-worker` 并检查健康、就绪与三角色命名空间权限。新增 SDK 最小权限
见 [Deployment 运维 RBAC](kubernetes-deployment-operations-rbac.yaml)，示例不会自动应用。

数据库故障或写入响应未知时保留目标锁；不提供自动清锁、自动重放或自动回滚。
单个观察步骤租约 180 秒，每 30 秒复用统一心跳续租；进程中断后等待到期再恢复只读核实。外部准入修改 spec
可能导致本操作被判为替代；这是保守核实行为，不能把其他发布计为本次成功。

临时工作计划及根 AGENTS.md 入口已在全部工作区验收完成后清理；正式文档保留设计与证据。
