# 一、准备环境

- 新建一个目录用来存放应用的helm chart和镜像，目录名推荐规则：`<应用名>-bundles`
- 环境要求：
  - 安装helm（如果准备的helm chart是tgz包，不需要打包，此要求可以忽略）
  - 容器运行时环境：containerd环境（或全量docker环境）
- helm chart和镜像的准备工作，需要有一定的容器相关知识和技能

## helm chart模板

- helm chart模板可以到这个网站查找：https://artifacthub.io/
- 也可以通过helm命令的方式获取： helm repo add xxx https://xxx; helm pull <具体helm chart模板> --version <version版本>
- helm chart需要是helm package打包完的制品（.tgz压缩文件）

## 镜像

- 将helm chart所需要的所有镜像导出为离线镜像文件（.tar压缩文件）
- 导出命令示例（以ctr举例）：ctr i export redis-8.targz docker.io/library/redis:8 docker.io/bitnami/os-shell:12-debian-12-r51 xxx


将helm chart模板文件（.tgz压缩文件）和镜像文件（.tar压缩文件）放到第一步新建的目录下

# 二、新增应用

在 `src/core/app_defaults` 下新增应用配置，具体配置可参考其他应用（建议参考redis）

- ps: 当然，这个步骤也可以让AI协助完成，通常prompt提示词为： `新增应用xxx，helm chart模板详见/xxx/xxx/xxx-bundles`

# 三、导入应用

## 导入helm chart和镜像

将 `<应用名>-bundles` 目录上传到容器云 `master01` 节点，执行以下命令导入：

```bash
source /opt/kubengine/env/bin/activate
kubengine-k8s sync-bitnami import-dir <应用名>-bundles/
```

## 注册应用

将新增应用的代码上传到 `master01` 节点的 `/opt/kubengine/src/core/app_defaults/` 目录下，执行以下命令进行注册：

```bash
source /opt/kubengine/env/bin/activate
kubengine app init-data
```

执行结果会有 `新增应用数量: 1` 信息，表示注册成功，即可在页面上部署测试
